# Independent gauge evidence audit

We checked four daily discharge files from [Ogbu's University of Bonn dataset](https://doi.org/10.60507/FK2/G3DT4G) against the project's evaluation periods. The [coverage table](coverage.csv) includes the file source, SHA-256, first and last usable date, missing values and number of overlapping three-date sequences. Run `python -m jobs.gauge_coverage` from the repository root to reproduce it.

The last usable date was January 2005 for Hadejia, November 1998 for Jamaare, May 2014 for Kaduna and December 2018 for Oroo. Only Oroo overlaps the project's 2016–2021 training period. None overlaps the 2022 calibration year or the held-out period beginning in 2023. Kaduna and Oroo share a station identifier in their file headers despite having different basin names. Resolve station identity from independent metadata before joining either to a geographic feature.

Three consecutive daily discharge readings describe sampling coverage at a river station. A high-flow threshold would need to be defined at that station and checked against dated inundation evidence. A low reading at that station cannot establish 72 hours without flooding elsewhere in the LGA. No training or test labels were generated from these records.

For Lokoja and Makurdi, [NEMA publishes comparative hydrographs](https://nema.gov.ng/download-daily-flood-water-level-report/). A [Federal Ministry update](https://fmino.gov.ng/federal-ministry-of-water-resources-sanitation-emphasizes-preparedness-against-flooding-in-nigeria/) also supplies dated readings for both in August 2023. These are useful cross-checks for station identity and units. The [NIHSA data service](https://nihsa.gov.ng/request-data) handles requests for measured station series. A useful extract would include station coordinates and ID, timestamps and timezone, measured stage or discharge with units, quality flags, missing dates and the history of any official alert thresholds in the same units and datum.
